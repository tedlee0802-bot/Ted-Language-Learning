## 2. 도착점에서 거꾸로 나눈 구간

```
365일 = 신규 50주(350일) + 최종 총복습 15일
  └ 50주 × 200단어 = 10,000단어
      └ 1주 = 월~목 29개 + 금~일 28개 = 200개
          └ 하루 = 새 단어 28~29 + 어제 단어 복습 28~29
헤일리: 1,800문장 ÷ 5문장 = 360일 (+5일 총복습)
딴딴영어: 1,120편 ÷ 350일 = 하루 3~4편 (+15일 총복습)
```

| 분기 | Day | 단어 순위 | 성격 | 헤일리 책 (순서) | 분기 말 점검 |
| --- | --- | --- | --- | --- | --- |
| Q1 | 1–91 | 1–2,600 | 기초 구어 (회화의 약 90%를 차지하는 단어) | 일상 생활 → 리액션 → 누구나 쓰는 말 2 → 회사 생활 1 → should 시작 | 누적 2,600 중 200개, 80% |
| Q2 | 92–182 | 2,601–5,200 | 일상·업무 확장 | should → could → would → 쇼핑 → what → that 시작 | 반기 시험 300개, 미드 1화 무자막 이해도 자가평가 |
| Q3 | 183–273 | 5,201–7,800 | 뉴스·비즈니스 | that → 회사 생활 2 → may/might/must → have pp 1 → have pp 2 시작 | 300개 |
| Q4 | 274–350 | 7,801–10,000 | 고급·전문 어휘 | have pp 2 → 수동태 → 사역동사 → 자주 쓰는 부사 → 브랜드 | 최종 300개 |
| 마무리 | 351–365 | 1–10,000 | 하루 약 715개씩 훑어보기 + 최종 시험 | 책별 한→영 총복습 | 1장의 도착점 확인 |

헤일리 책 순서를 정한 이유: 쉬운 일상·리액션 표현으로 입을 먼저 풀고, Ted가 업무에 바로 쓸 **회사 생활 1**을 4번째에 둡니다. 그다음 조동사(should/could/would) → 관계사(what/that) → 시제(have p.p.) → 수동태·사역동사 순으로 문법 난이도를 올립니다. Ted가 연습 중인 시제(have p.p.)는 Q3~Q4, 수동태는 Q4(Day 281~300)에 문장으로 정리합니다. 책 한 권은 20일이 걸립니다.

## 4. 의사결정과 근거

| 결정 | 선택 | 이유 |
| --- | --- | --- |
| 빈도 기준 | 미국 드라마·영화 자막(OpenSubtitles) 50% + 종합 코퍼스(wordfreq) 50% | "미국인이 실제로 많이 쓰는" 구어를 반영하되, 뉴스·업무 어휘도 빠지지 않게 합니다 |
| 단어 단위 | 원형(lemma): went·going → go | 같은 단어를 여러 번 세지 않습니다. 다만 meeting·according·amazing처럼 독립적으로 쓰이는 형태는 따로 넣었습니다 |
| 발음기호 | CMU 발음사전 → 미국식 IPA 자동 변환 | General American 기준으로 통일했습니다 |
| 예문 | 헤일리쌤 문장 우선, 없으면 WordNet 사전 예문 | 1,316개 단어는 실제 미드 문장과 한국어 해석으로 바로 배웁니다 |
| 제외 | 고유명사(나라·도시·사람 이름, American·Monday 등 대문자 단어), 성적 비속어 | 고유명사는 따로 외울 필요가 적습니다. shit·damn 같은 흔한 비속어는 `비속어(이해용)`으로 표시만 하고 남겼습니다 |
| 복습 간격 | 어제(D-1) 필수 + D-7·D-30 선택 | 요청하신 "어제 복습"을 기본으로 하고, 장기 기억을 위해 간격 복습을 덧붙였습니다 |

## 5. Anna의 비판: 실패로 이어질 수 있는 지점

1. **분량이 많습니다.** 1년 동안 매일 70분, 365일입니다. 단어를 공부하는 사람 대부분이 4~6주차에 멈춥니다. → 바쁜 날의 최소 루틴과 주말 따라잡기 규칙을 미리 정했습니다.
2. **복습량이 계속 쌓입니다.** 하루 28개는 6개월 뒤 누적 5,000개가 됩니다. 어제 범위 복습만으로는 그중 상당수를 잊습니다. → Anki 파일(`Ted_Anki_10000단어.tsv`)을 가져와 간격 반복을 자동화하는 것을 강하게 권합니다.
3. **빈도 순서가 Ted의 업무와 다릅니다.** quotation·lead time·MOQ·bezel 같은 LED·해외영업 용어는 일반 빈도 순위에서 뒤로 밀립니다. → 매주 업무 단어 10개를 따로 추가하는 트랙을 제안합니다.
4. **듣기만 하면 말하기가 늘지 않습니다.** 쉐도잉 다음에 한국어만 보고 영어로 말하는 단계가 핵심입니다. 시트의 `한국어` 열을 가리고 말해 보세요.
5. **딴딴영어 예문은 썸네일 글자 인식(OCR)으로 뽑았습니다.** 오타가 일부 남아 있을 수 있으니, 이상한 문장은 Shorts 링크로 영상을 확인하세요.

## 7. 딴딴영어 자료를 만든 방법

1. 채널 Shorts 목록 1,177편을 수집했습니다(제목·링크).
2. 각 Shorts 썸네일에 적힌 **핵심 패턴 + 한국어 뜻 + 예문 3개**를 글자 인식(Tesseract OCR)으로 읽고, 영어 철자를 사전으로 보정했습니다.
3. 한국어 뜻은 OCR 정확도가 낮아서 Anna가 1,120개를 직접 다시 썼습니다.
4. 순서: 패턴은 001→809 번호순, 생활 표현은 업로드순으로 하고, 두 목록을 비율에 맞게 섞어 하루 3~4편씩 배정했습니다.
5. 새 Shorts가 올라오면 Anna가 같은 방법으로 시트 끝에 추가할 수 있습니다.
