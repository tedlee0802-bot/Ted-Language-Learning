# Ted-Language-Learning
Foreign Language Scheduller / Personal AI-powered language learning platform

## Lingo Daily

매일의 언어 학습 계획과 진도를 관리하고, 영어·중국어 단어와 숙어를 복습하는 개인 학습 사이트입니다.

- 언어별 학습 계획, 일일 목표, 학습량 기록과 진도 차트
- 영어 20단어 + 10숙어, 중국어 20단어 + 5표현의 평일 학습
- 발음 표기와 브라우저 음성 재생, 전날 복습과 저녁 시험
- 주말 누적 시험, 오답·간격 복습, 휴대폰용 단어장 PNG 저장
- 가족 프로필과 PIN 로그인: 같은 수업을 보고 진도·시험 기록은 사람마다 따로 저장
- 휴대폰 홈 화면에 설치하는 웹앱(PWA)
- 화면 디자인은 `design-concepts/`의 시안 A(Calm Focus)를 적용

기존 Sites 소스의 커밋 `65e0900cc5fc846b7859cff5fab645e0fdc87209`에서 가져왔습니다. `web/`, `worker/`, `scripts/`, `tests/`는 해당 소스와 동일합니다. 기존 GitHub 초기 커밋도 유지합니다.

## 로컬 실행

Node.js 22 이상을 사용합니다. 별도 패키지 설치는 필요하지 않습니다. 업로드 검증에는 Node.js 24를 사용했습니다.

```sh
git clone https://github.com/tedlee0802-bot/Ted-Language-Learning.git
cd Ted-Language-Learning
cp .openai/hosting.example.json .openai/hosting.json
node scripts/build.mjs
node scripts/preview.mjs
```

브라우저에서 http://localhost:4173 을 엽니다. Windows PowerShell에서는 `cp` 대신 `Copy-Item`을 사용할 수 있습니다.

로컬 숙제·시험 저장소는 메모리에서 동작하므로 서버를 종료하면 초기화됩니다. 대시보드 기록은 해당 브라우저의 localStorage에 남습니다. 미리보기 서버는 신뢰할 수 있는 로컬 환경에서 사용하세요.

## 테스트

```sh
node --test tests/homework.test.mjs tests/family.test.mjs
```

수업별 문항 수, 한국 시간에 따른 공개 시각, 전날 복습 조건, 채점, 오답·장기 복습 기록과 중복 입력 방지를 검증합니다. `family.test.mjs`는 프로필 설정, 사람별 기록 분리, PIN 잠금, 코치 API 권한, PIN 변경·로그아웃을 검증합니다.

## 가족이 함께 쓰기 (프로필 · PIN)

처음에는 기존과 똑같이 한 사람용으로 동작합니다. **설정 → 가족과 함께 쓰기 → 내 프로필 만들기**에서 이름과 PIN을 정하면 가족 모드가 켜집니다.

- 첫 프로필이 관리자입니다. 지금까지의 숙제·시험 기록은 이 프로필에 그대로 남습니다(저장 위치도 그대로입니다).
- 관리자는 설정의 **가족 관리**에서 가족을 추가하고, PIN 재설정·이름 변경·삭제를 할 수 있습니다. 가족은 자기 PIN만 바꿀 수 있습니다.
- 수업은 모두 같고, 진도(학습 확인)·시험 결과·오답·간격 복습·수준 설정은 사람마다 `users/<id>/` 아래에 따로 저장됩니다.
- PIN은 숫자 4~8자리이고 서버에는 PBKDF2 해시만 저장됩니다. 5번 틀리면 그 프로필은 15분 동안 잠깁니다. 로그인은 180일 유지되며 설정의 **다른 사람으로 전환**으로 로그아웃합니다.
- 체크리스트(대시보드) 기록은 기존처럼 각 기기의 브라우저에 저장되며, 같은 기기를 함께 써도 사람별로 따로 보관됩니다.
- PIN은 간단한 가족용 잠금입니다. 사이트를 공개 주소로 열면 누구나 프로필 목록(이름)은 볼 수 있으니 6자리 이상 PIN을 권장합니다.

## 휴대폰 앱 설치 (PWA)

사이트에 `manifest.webmanifest`, 서비스 워커(`sw.js`)와 아이콘이 들어 있어 휴대폰 홈 화면에 앱으로 설치됩니다. 앱 안의 **설정 → 앱 설치 방법**에 기기별 안내와 링크 공유 버튼이 있습니다.

- iPhone·iPad: Safari로 사이트 열기 → 공유 버튼 → 홈 화면에 추가
- Android: Chrome으로 사이트 열기 → ⋮ 메뉴 → 앱 설치(또는 홈 화면에 추가)

설치에는 HTTPS 주소가 필요합니다(Sites 주소는 HTTPS입니다). 앱 화면은 오프라인에서도 열리지만, 수업·시험·기록은 항상 서버에서 받아오므로 인터넷이 필요합니다. 사이트를 다시 배포하면 설치된 앱도 다음 실행 때 새 버전으로 바뀝니다.

## 배포 순서 (가족 사용)

1. 이 브랜치를 기존 Sites 프로젝트에 배포합니다. 사이트가 아직 본인 전용인 상태에서 진행합니다.
2. 본인이 사이트에 들어가 **설정 → 내 프로필 만들기**로 관리자 프로필과 PIN을 만듭니다. 이 단계 전에 사이트를 공개하면 다른 사람이 먼저 관리자를 만들 수 있으니 순서를 지켜주세요.
3. **가족 관리 → 가족 추가**로 June과 Erin의 프로필·PIN을 만듭니다.
4. 코치 예약 작업(수업 추가·공개)을 계속 쓰려면 Worker 비밀 값 `COACH_KEY`를 설정하고, 예약 작업이 `X-Coach-Key` 헤더로 보내게 합니다(`COACH_OPERATIONS.md` 참고). 가족 모드에서는 관리자 로그인 또는 이 키 없이 코치 API를 호출할 수 없습니다.
5. Sites에서 가족이 사이트 주소에 접속할 수 있도록 공개 범위를 바꿉니다. 이 설정은 Sites에서 직접 해야 하며 이 저장소로는 바뀌지 않습니다.
6. 가족에게 주소를 보내고 앱 설치 방법을 안내합니다.

## 배포와 데이터

기존 사이트는 Sites에서 계속 운영합니다. 이 GitHub 업로드는 기존 사이트의 배포, 접근 권한, 저장 데이터를 변경하지 않습니다. GitHub Pages용 정적 배포 설정은 포함하지 않습니다. 숙제와 시험 기능에는 서버와 R2 `BUCKET` 바인딩이 필요합니다.

실제 배포에는 기존 프로젝트의 `.openai/hosting.json`과 비공개 인증 설정을 사용해야 합니다. 예시 설정의 프로젝트 ID는 로컬 빌드용 자리표시자입니다. 이 설정으로 새 Sites 프로젝트를 만들거나 기존 사이트를 덮어쓰지 마세요.

오전 07:30·오후 19:00의 공개 조건은 코드에 구현되어 있습니다. 정시 수업 생성·예약 실행은 별도 연결이 필요하며 이 저장소만으로 활성화되지 않습니다. 초기 자료는 2026년 10월 19~23일분이며, 이후 수업은 운영 API로 추가해야 합니다. 브라우저 음성은 기기에 설치된 음성을 사용합니다.

공개 저장소에는 비밀키, 실제 배포 설정, 개인 프로필·성적·학습 기록, 브라우저 백업, 생성된 `dist/`와 Sites 저장소의 과거 Git 이력을 포함하지 않습니다. 기본 단어·숙어와 테스트의 임시 데이터만 포함합니다.
